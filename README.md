# infra

Данный репозиторий содержит инфраструктурную часть проекта, позволяющую развернуть приложение

## Требования

1. Docker
2. Docker-compose
3. Свободное место

## Развертывание

1. Склонировать репозитории сервисов в одну директорию
2. Перейти в `infra`
3. Создать .env файл с настройками
4. Выполнить `scripts/up.sh`

Для закрытия приложения выполнить `scripts/down.sh`

## Структура проекта

```
.
├── docker-compose.yml               # docker-compose файл для сборки сервисов
├── LICENSE
├── nginx                            # Директория для конфигурации nginx
│   └── nginx.conf                   # Базовая конфигурация nginx: роутинг и прокси
├── postgres                         # Скрипты конфигурации postgres sql
│   └── init                         # Инициализация базы данных
│       ├── 01-create-dbs-users.sh   # Создание пользователей
│       └── 02-grants.sh             # Предоставление прав пользователям
├── README.md
└── scripts                          # Скрипты для работы
    ├── down.sh                      # Закрытие приложения
    ├── reset-db.sh                  # Перезагрузка с потерей данных
    └── up.sh                        # Старт сервиса
```
